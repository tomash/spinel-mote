# STM32F103C8 (WeAct blue pill) target

Bare-metal spinel on a Cortex-M3, 64 KB flash / 20 KB SRAM, behind the
board's Maple / STM32duino USB bootloader. First run on hardware
2026-11-14: `app/stm32/blink.rb` (PC13, a rescued exception driving the
pattern) blinks as written.

## Build

```
SPINEL_SRC=~/spinel-size-floor   # branch mcu-trim
RT_DEFS="-I$PWD/baremetal/arm-include -I$PWD/baremetal/include -include $PWD/baremetal/noenv.h \
  -DSP_NO_GC_PHASES -DSP_NO_SLAB -DCLOCK_MONOTONIC=4"
RT_OPT=-Os RT_DEFS="$RT_DEFS" SPINEL_PRESET=tiny RT_SUFFIX=-tiny tools/build-rt.sh cortex-m3
CROSS=arm-none-eabi- ARCH_FLAGS="-mcpu=cortex-m3 -mthumb -mfloat-abi=soft" \
CRT0=baremetal/stm32f103/crt0.c LDSCRIPT=baremetal/stm32f103/stm32f103.ld FLASH_KB=56 RAM_KB=20 \
SPINEL_PRESET=tiny SPINEL_FLAGS="--no-bigint --proc-arg-slots=16" RT_DIR=build/rt-cortex-m3-tiny \
APP_OPT=-Os APP_DEFS="-I$PWD/baremetal/arm-include -I$PWD/baremetal/include -DSP_NO_SLAB -DSP_NO_GC_PHASES -DCLOCK_MONOTONIC=4" \
EXTRA_SRCS="baremetal/tinystdio.c baremetal/setjmp_armv7m.S" LINK_FLAGS="-Wl,-z,muldefs" \
  tools/ch32-size.sh app/stm32/blink.rb
arm-none-eabi-objcopy -O binary build/ch32/blink.elf build/stm32-blink.bin
```

blink.rb: 44 833 B flash (of the 56 KB the bootloader leaves), 4 300 B
static RAM. The CH32's FFI-only blink is 42 853 B / 4 044 B on ARM.

## Flash (keeps the bootloader)

The bootloader is a DFU device (`1eaf:0003`) for ~1.5 s after reset, then
jumps to 0x08002000. Alt 2 is "Upload to Flash 0x8002000"; alt 1 is the
old 0x8005000 layout; alt 0 (RAM) is refused. Never write 0x08000000.

udev (root, once): `SUBSYSTEM=="usb", ATTR{idVendor}=="1eaf",
ATTR{idProduct}=="0003", MODE="0660", GROUP="dialout"` in
`/etc/udev/rules.d/61-maple-dfu.rules`.

The board is on hub port `1-3.1` / `2-3.1`; power-cycling it opens the
window, so no button press is needed:

```
uhubctl -l 1-3 -p 1 -a off; uhubctl -l 2-3 -p 1 -a off; sleep 1
uhubctl -l 1-3 -p 1 -a on;  uhubctl -l 2-3 -p 1 -a on
until lsusb -d 1eaf:0003 >/dev/null; do sleep 0.05; done
dfu-util -d 1eaf:0003 -a 2 -D build/stm32-blink.bin -R
```

## Board layer

- `baremetal/stm32f103/crt0.c`: vector table, reset (VTOR = 0x08002000,
  .data, .bss, constructors, main), a fault blinks PC13 fast, an exit leaves
  it on (0) or blinks slowly (non-zero). No console yet: `board_putchar`
  drops bytes (USART1 on PA9/PA10 is the next step).
- `shim/esp32/src/ucontext_armv7m.S`: the runtime's coroutine switch.
- `baremetal/setjmp_armv7m.S`: 40-byte jmp_buf (newlib's is 160).
- `baremetal/arm-include/sys/dirent.h`: arm-none-eabi newlib's is #error.

## Size note

`String#split` in the same program takes it to 138 KB: it pulls
`sp_str_cold` (18 KB), `sp_dtoa` (15 KB) and `sp_bigint` (13 KB, despite
`--no-bigint`), plus strftime and strerror. The next size lever for real
programs on 64 KB parts.
